### [문제 6] 회원 등급 판정 함수 완성하기(다중 조건)
(정답)
[조건] 요약:
1. 구매금액이 100000원 이상이고, **동시에** 방문횟수가 5회 이상이면 `'VIP'`를 반환한다.
2. 1번 조건이 아니면서, 구매금액이 50000원 이상이거나 방문횟수가 3회 이상이면(**둘 중 하나만 만족해도**) `'일반'`을 반환한다.
3. 그 외에는 `'신규'`를 반환한다.

참고용 파이썬 표현(블록 논리를 코드로 옮기면 — 실제로는 이 로직을 AI 코디니 블록으로 조립합니다):
```python
def get_grade(purchase_amount, visit_count):
    if purchase_amount >= 100000 and visit_count >= 5:
        return 'VIP'
    elif purchase_amount >= 50000 or visit_count >= 3:
        return '일반'
    else:
        return '신규'
```
(해설)
'그리고(and)'와 '또는(or)'을 조건문에 함께 써서 여러 조건을 조합합니다. `elif`는 위 조건이 거짓일 때만 검사합니다.
(배점) 15점
