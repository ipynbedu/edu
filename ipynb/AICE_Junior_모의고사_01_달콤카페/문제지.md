# AICE Junior 모의고사 — 문제지

합격선: 100점 만점에 **80점 이상**

이 시험은 노코드 도구 **AIDU ez**로 풉니다. 아래 `data.csv`를 AIDU ez에 업로드한 뒤, 문제마다 안내된 메뉴를 사용해 확인·계산하세요. 뒤 문항은 앞 문항에서 처리한 결과(가공된 데이터, 학습된 모델)를 이어서 사용합니다 — 반드시 순서대로 푸세요.

사용 데이터 파일: `data.csv`


## 배경

**달콤카페 마케팅팀**

달콤카페 마케팅팀은 고객의 이용 패턴 데이터를 바탕으로 재방문 여부를 예측하여, 재방문 가능성이 낮은 고객에게 쿠폰을 보내는 프로모션에 활용하고자 한다.

**과제**: 카페 고객 데이터를 활용해 재방문 여부를 예측하는 AI 모델을 만들어보자


## 데이터 컬럼

| 컬럼명 | 설명 |
|---|---|
| customer_id | 고객번호 (고유번호) |
| avg_spend | 평균 결제금액(원) |
| visit_count | 최근 3개월 방문횟수 |
| membership_month | 가입 후 경과월수 |
| age_group | 연령대 |
| membership_type | 멤버십 등급 |
| revisit | 재방문여부 (종속변수) |


---
## 문제


### [문제 1] 종속변수(출력 컬럼) 찾기
- 유형: 문제 유형 판별
- 배점: 15점

종속변수(output 컬럼)란 독립변수(input 컬럼)를 바탕으로 예측하는 대상을 의미한다. 다음 중 이 과제(카페 고객 데이터를 활용해 재방문 여부를 예측하는 AI 모델을 만들어보자)를 해결하는 데 필요한 종속변수를 고르시오.
(1) 평균 결제금액(원)
(2) 멤버십 등급
(3) 연령대
(4) 재방문여부


### [문제 2] 전체 데이터 개수
- 유형: 데이터 탐색(EDA)
- 배점: 10점
- 활용 메뉴: [데이터 분석 - 기초정보분석]

데이터의 전체 개수(observation)를 작성하시오.
※ 답안 형식: 정수


### [문제 3] 평균값 확인
- 유형: 데이터 탐색(EDA)
- 배점: 15점
- 활용 메뉴: [데이터 분석 - 기초정보분석]

'최근 3개월 방문횟수(visit_count)'의 평균(mean)을 작성하시오.
※ 답안 형식: 소수점 둘째 자리까지


### [문제 4] 상관관계 읽기 (음의)
- 유형: 데이터 탐색(EDA)
- 배점: 15점
- 활용 메뉴: [데이터 분석 - 시각화 분석] (히트맵)

'가입 후 경과월수(membership_month)'과(와) 가장 큰 음의 상관관계를 갖는 변수를 고르시오.
(1) 평균 결제금액(원)
(2) 최근 3개월 방문횟수


### [문제 5] 결측치 대체하기
- 유형: 데이터 전처리
- 배점: 15점
- 활용 메뉴: [데이터 가공]

결측치를 다음 규칙으로 대체하시오 — 수치형 변수는 중앙값(median), 범주형 변수는 최빈값(most_frequent). 대체한 뒤, '연령대'의 최빈값 비율(%)을 작성하시오.
※ 답안 형식: 소수점 둘째 자리까지 (예: 12.34)


### [문제 6] 딥러닝(MLP) 모델 Accuracy 확인
- 유형: 딥러닝 모델 학습
- 배점: 20점
- 활용 메뉴: [AI 모델 학습 - 딥러닝]

다음 조건으로 딥러닝 모델을 학습하시오 — 은닉층 1개(노드 32개), 활성화함수 relu, 최대 반복(Epochs) 300회. 학습된 모델의 Accuracy 값을 작성하시오.
※ 답안 형식: 반올림하여 소수점 넷째 자리까지 (예: 0.9123)


### [문제 7] 중요 변수 확인
- 유형: 변수 영향도 해석
- 배점: 10점
- 활용 메뉴: [AI 모델 활용 - 변수 영향도 확인]

학습된 모델에서 예측에 가장 큰 영향을 주는 변수(1위)를 고르시오.
(1) 평균 결제금액(원)
(2) 최근 3개월 방문횟수
(3) 가입 후 경과월수
(4) 연령대


---
> 참고: 이 문제지의 딥러닝 단계는 scikit-learn MLP로 근사 재현한 것이라, 실제 AIDU ez 결과와 소수점 단위까지 정확히 일치하지 않을 수 있습니다. 해설지의 정답은 채점용 기준값(허용오차 포함)입니다.
