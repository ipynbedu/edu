# AICE Basic 모의고사 — 문제지

합격선: 100점 만점에 **80점 이상**

이 시험은 노코드 도구 **AIDU ez**로 풉니다. 아래 `data.csv`를 AIDU ez에 업로드한 뒤, 문제마다 안내된 메뉴를 사용해 확인·계산하세요. 뒤 문항은 앞 문항에서 처리한 결과(가공된 데이터, 학습된 모델)를 이어서 사용합니다 — 반드시 순서대로 푸세요.

사용 데이터 파일: `data.csv`


## 배경

**무비플레이 콘텐츠추천팀**

OTT 서비스 '무비플레이'의 콘텐츠추천팀은 고객별 시청 데이터를 바탕으로 특정 장르에 대한 선호도를 예측하는 모델을 만들면, 개인화된 콘텐츠를 추천해 시청 만족도와 이용 시간을 늘릴 수 있을 것으로 기대한다. 다양한 장르 중 이번에는 '액션 장르'에 대한 선호도를 모델링한다.

**과제**: 고객 시청 데이터를 활용해 액션 장르 선호 여부를 예측하는 AI 모델을 만들어보자


## 데이터 컬럼

| 컬럼명 | 설명 |
|---|---|
| customer_id | 고객번호 (고유번호) |
| total_watch_count | 총 시청건수 |
| action_watch | 액션 시청건수 |
| drama_watch | 드라마 시청건수 |
| comedy_watch | 코미디 시청건수 |
| age_group | 연령대 |
| membership_type | 멤버십 등급 |
| prefer_action | 액션장르선호여부 (종속변수) |

## 문제


### [문제 1] 알맞은 알고리즘 유형
- 유형: 문제 유형 판별
- 배점: 10점

본 과제(고객 시청 데이터를 활용해 액션 장르 선호 여부를 예측하는 AI 모델을 만들어보자) 해결에 알맞은 알고리즘의 유형을 고르시오.
(1) 분류모형
(2) 회귀모형
(3) 군집모형
(4) 시계열모형


### [문제 2] 결측치가 있는 변수 찾기
- 유형: 데이터 탐색(EDA)
- 배점: 5점
- 활용 메뉴: [데이터 분석 - 기초정보분석]

결측치(빠진 값)가 있는 변수를 고르시오.
(1) 연령대
(2) 멤버십 등급
(3) 총 시청건수
(4) 고객번호


### [문제 3] 조건에 맞는 데이터 수 세기
- 유형: 데이터 탐색(EDA)
- 배점: 10점
- 활용 메뉴: [데이터 분석 - 기초정보분석]

'연령대(age_group)'가 '20대'인 데이터의 수를 작성하시오.
※ 답안 형식: 정수


### [문제 4] 기술통계량 읽기
- 유형: 데이터 탐색(EDA)
- 배점: 5점
- 활용 메뉴: [데이터 분석 - 기초정보분석]

'코미디 시청건수(comedy_watch)'의 기술통계량을 확인해, 평균(mean)과 표준편차(std) 중 어느 쪽이 더 큰지 고르시오.
(1) 표준편차(std)가 더 크다
(2) 평균(mean)이 더 크다


### [문제 5] 상관관계 읽기 (양의)
- 유형: 데이터 탐색(EDA)
- 배점: 10점
- 활용 메뉴: [데이터 분석 - 시각화 분석] (히트맵)

'총 시청건수(total_watch_count)'과(와) 가장 큰 양의 상관관계를 갖는 변수를 고르시오.
(1) 액션 시청건수
(2) 드라마 시청건수
(3) 코미디 시청건수


### [문제 6] 조건에 맞는 데이터 수 세기
- 유형: 데이터 탐색(EDA)
- 배점: 5점
- 활용 메뉴: [데이터 분석 - 기초정보분석]

'멤버십 등급(membership_type)'이 '베이직'인 데이터의 수를 작성하시오.
※ 답안 형식: 정수


### [문제 7] 결측치 대체하기
- 유형: 데이터 전처리
- 배점: 10점
- 활용 메뉴: [데이터 가공]

결측치를 다음 규칙으로 대체하시오 — 수치형 변수는 중앙값(median), 범주형 변수는 최빈값(most_frequent). 대체한 뒤, '연령대'의 최빈값 비율(%)을 작성하시오.
※ 답안 형식: 소수점 둘째 자리까지 (예: 12.34)


### [문제 8] 모델 3종 비교 (Accuracy 기준)
- 유형: 머신러닝 모델 비교
- 배점: 10점
- 활용 메뉴: [AI 모델 학습 - 머신러닝]

다음 3개의 머신러닝 모델(Logistic Regression, Decision Tree, Random Forest)을 각각 학습하고 비교하시오. Accuracy 기준으로 가장 성능이 좋은 모델을 고르시오.
(1) Logistic Regression
(2) Decision Tree
(3) Random Forest


### [문제 9] 딥러닝(MLP) 모델 Accuracy 확인
- 유형: 딥러닝 모델 학습
- 배점: 10점
- 활용 메뉴: [AI 모델 학습 - 딥러닝]

다음 조건으로 딥러닝 모델을 학습하시오 — 은닉층 1개(노드 32개), 활성화함수 relu, 최대 반복(Epochs) 300회. 학습된 모델의 Accuracy 값을 작성하시오.
※ 답안 형식: 반올림하여 소수점 넷째 자리까지 (예: 0.9123)


### [문제 10] 중요 변수 확인
- 유형: 변수 영향도 해석
- 배점: 5점
- 활용 메뉴: [AI 모델 활용 - 변수 영향도 확인]

학습된 모델에서 예측에 가장 큰 영향을 주는 변수(1위)를 고르시오.
(1) 액션 시청건수
(2) 총 시청건수
(3) 드라마 시청건수
(4) 코미디 시청건수


### [문제 11] 새 입력값으로 예측하기
- 유형: 예측/시뮬레이션
- 배점: 10점
- 활용 메뉴: [AI 모델 활용 - 시뮬레이션]

다음 입력값에 대한 모델의 예측 결과를 고르시오. (총 시청건수=56.0, 액션 시청건수=0.0, 드라마 시청건수=6.0, 코미디 시청건수=16.0, 연령대=30대, 멤버십 등급=베이직)
(1) 선호
(2) 비선호


### [문제 12] 여러 구성으로 모델 고도화
- 유형: 모델 성능 개선
- 배점: 10점
- 활용 메뉴: [AI 모델 학습 - 딥러닝] (파라미터를 바꿔 재학습)

은닉층 구성을 3가지(① 1개층·32개노드 ② 1개층·64개노드 ③ 2개층·64+32개노드)로 바꿔가며 각각 최대 반복(Epochs) 500회로 다시 학습하고 비교하시오. 그중 가장 좋은 Accuracy(기존 결과보다 나쁘면 기존 결과 유지)를 작성하시오.
※ 답안 형식: 반올림하여 소수점 넷째 자리까지
