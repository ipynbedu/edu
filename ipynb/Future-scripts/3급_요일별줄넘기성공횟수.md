# [3급(입문) 실습] 데이터 테이블과 그래프 — 요일별 줄넘기 성공 횟수

**사용 데이터**: [`../data/3급_요일별줄넘기성공횟수.csv`](../data/3급_요일별줄넘기성공횟수.csv)

**실습 위치**: [aicodiny.com](https://aicodiny.com) 접속 → 상단 메뉴에서 'AI와 데이터 과학' 섹션으로 이동 → 아래 안내에 맞는 실습 카드를 선택하세요.

---
## 목표

'요일'에 따라 '성공 횟수(회)'이 어떻게 달라지는지 표로 만들고 그래프로 확인합니다.

## 데이터 미리보기

| 요일 | 성공 횟수(회) |
|---|---|
| 월 | 69 |
| 화 | 47 |
| 수 | 62 |
| 목 | 68 |
| 금 | 26 |

## 실습 순서

1. aicodiny.com에서 **'데이터 테이블과 그래프'** 실습(또는 '데이터 테이블 사용해보기')을 엽니다.
2. **테이블 만들기** 블록으로 새 표를 만들고, 열 이름을 위 데이터와 똑같이 입력합니다 (요일 / 성공 횟수(회)).
3. 위 표의 값을 한 행씩 손으로 입력합니다 (총 5행 — 어렵지 않은 양입니다).
4. **그래프 만들기** 블록을 연결해 막대그래프를 실행해봅니다. 이어서 라인그래프로도 바꿔서 실행해봅니다.
5. 두 그래프를 비교해보고 아래 생각해보기 질문에 답해봅니다.

## 생각해보기

- 이 표에서 '성공 횟수(회)'가 가장 큰 요일과 가장 작은 요일은 각각 무엇인가요?
- '요일'은 수치형 데이터인가요, 범주형 데이터인가요? 그렇게 생각한 이유는?
- 막대그래프와 라인그래프 중 이 데이터에는 어느 쪽이 더 어울린다고 느꼈나요? 이유는?

> 힌트: 정답을 맞히는 문제가 아니라 실습입니다 — 그래프를 직접 만들어보고 눈으로 비교한 뒤 스스로 답을 적어보세요. `../../variants/`의 관련 객관식 문항(데이터 관리 카테고리)과 이어집니다.
