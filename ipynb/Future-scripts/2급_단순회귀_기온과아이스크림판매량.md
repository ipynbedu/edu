# [2급(심화) 실습] 단순 회귀 분석 — 기온과 아이스크림 판매량

**사용 데이터**: [`../data/2급_단순회귀_기온과아이스크림판매량.csv`](../data/2급_단순회귀_기온과아이스크림판매량.csv)

**실습 위치**: [aicodiny.com](https://aicodiny.com) 접속 → 상단 메뉴에서 'AI와 데이터 과학' 섹션으로 이동 → 아래 안내에 맞는 실습 카드를 선택하세요.

---
## 목표

'기온(℃)'이 '아이스크림 판매량(개)'에 어떤 영향을 주는지 회귀 분석으로 확인합니다.

## 데이터 미리보기

| 기온(℃) | 아이스크림 판매량(개) |
|---|---|
| 20 | 70 |
| 23 | 87 |
| 24 | 116 |
| 25 | 106 |
| 27 | 113 |
| 28 | 114 |
| 30 | 145 |

## 실습 순서

1. aicodiny.com에서 **'단순 회귀 분석'** 실습을 엽니다.
2. 독립변수(x)에 '기온(℃)', 종속변수(y)에 '아이스크림 판매량(개)' 값을 위 표대로 입력합니다.
3. 분석을 실행하고 화면에 나오는 회귀선(예측선)을 확인합니다.
4. 회귀선이 오른쪽 위로 올라가는지(양의 관계), 오른쪽 아래로 내려가는지(음의 관계) 관찰합니다.

## 생각해보기

- 기온(℃)이 늘어나면 아이스크림 판매량(개)는 대체로 늘어나나요, 줄어드나요?
- 표에 없는 새로운 기온(℃) 값 하나를 골라, 회귀선을 보고 아이스크림 판매량(개)를 대략 얼마로 예측할 수 있을지 짐작해보세요.
- 이 실습은 지도학습 중 분류와 회귀 중 어느 쪽에 해당하나요?

> 힌트: `../../variants/`의 머신러닝 카테고리 문항(분류 vs 회귀, 학습용/평가용 나누기)과 이어지는 실습입니다.
